# Expense Tracker PWA

This is the no-Mac/no-Xcode version.

It is a Progressive Web App. Expenses are stored in the browser's localStorage on the device.

## Put it online
The easiest free option is GitHub Pages. Create a repository, upload `index.html`, `manifest.json`, and `sw.js`, then enable Pages for the repository. GitHub Pages publishes static files and provides HTTPS.

## On iPhone
Open the published URL in Safari -> Share -> Add to Home Screen -> Add.

The resulting icon launches the tracker like an app.

IMPORTANT: the data is local to the browser/device. If you clear Safari website data, the expenses can be lost. This version has no cloud backup yet.
