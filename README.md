# Expense & Sales Tracker PWA

A local iPhone-friendly PWA for tracking expenses and daily sales.

## Expenses
- Categories: Housing, Groceries, Eating Out, Transport, Shopping, Utilities, Insurance, Health, Subscriptions, Entertainment, Travel, Family, Education, Personal, Other
- Date, amount, subcategory, payment method and notes
- Monthly totals and category breakdown
- Search and delete

## Sales
- Record daily **Cash Sales**
- Record daily **Bank Sales**
- Automatically calculates **Total Sales = Cash Sales + Bank Sales**
- One sales entry per day; saving again for the same day updates that day's figures
- Monthly sales totals

All data is stored locally on the device/browser.
